Trans-Jimaku Gemini Web 隐私政策

最后更新日期：2026-07-18

本隐私政策适用于浏览器扩展 Trans-Jimaku Gemini Web。 该扩展的唯一用途，是在用户手动触发采集时，为 Trans-Jimaku 桌面应用采集 Gemini Web 账号接入所需参数， 并通过本机回环地址发送给正在同一设备上运行的桌面应用。

1. 我们处理哪些数据

当用户手动点击扩展中的采集按钮时，扩展可能会处理以下数据：

  • 已登录 Gemini / Google 账号的邮箱地址
  • 与 Gemini Web 账号接入相关的会话认证数据，例如 Google / Gemini 会话 cookies
  • Gemini 页面中的接入参数，例如 at_value、bl_value 以及与账号接入相关的页面参数
  • 为完成本地接入流程所需的最小本地状态信息

2. 我们为何处理这些数据

这些数据仅用于以下目的：

  • 识别用户当前浏览器中已登录的 Gemini Web 账号
  • 为 Trans-Jimaku 桌面应用建立 Gemini Web 账号接入配置
  • 支持桌面应用后续对已接入账号进行轮转、状态检测与模型可用性检测

3. 数据何时会被处理

扩展不会在后台持续扫描用户页面，也不会在未触发操作时自动采集数据。 只有当用户明确点击扩展中的采集按钮后，扩展才会开始访问 Gemini 相关页面并执行参数采集。

4. 数据会发送到哪里

扩展采集到的数据仅会发送到用户本机运行中的 Trans-Jimaku 桌面应用， 使用的地址为本机回环接口，例如 http://127.0.0.1:8765/。

扩展本身不会将这些数据发送到开发者控制的远程服务器，也不会用于广告投放、用户画像、跨站跟踪或出售给第三方。

5. 数据是否会被保存

扩展仅保存完成接入流程所需的最小本地状态。与账号接入相关的数据可能会被桌面应用保存到本地配置中， 以便后续使用 Gemini Web 功能。该部分本地保存行为由 Trans-Jimaku 桌面应用负责。

6. 用户如何控制和删除数据

  • 用户可以随时停止使用本扩展并将其卸载
  • 用户可以在 Trans-Jimaku 桌面应用中删除已接入的 Gemini Web 账号
  • 用户也可以清除浏览器中的相关登录状态，以阻止扩展再次读取对应会话数据

7. 第三方服务

本扩展运行过程中可能会访问 Gemini 和 Google 相关页面，以完成用户主动发起的账号接入。 这些页面及其服务由第三方提供，并受其各自的条款和隐私政策约束。

8. 隐私政策更新

如扩展的数据处理方式发生变化，本页面会同步更新。更新后的版本将以本页面标注的最后更新日期为准。

English Summary

Trans-Jimaku Gemini Web is a browser extension used only to collect Gemini Web account connection parameters for the Trans-Jimaku desktop application after the user manually starts collection.

The extension may process signed-in account email, Google / Gemini session cookies, and Gemini page connection parameters. The collected data is sent only to the locally running Trans-Jimaku desktop application through localhost, and is not sent by the extension to the developer's remote servers.
